# Central Impulso — Portal do Cliente

Plataforma pública de descoberta das pesquisas do Instituto Impulso.

URL: https://impulsoflow.github.io/Central-Impulso/

## Estado atual (2026-10-10)

- Catálogo responsivo de seis pesquisas com links públicos verificados.
- Indicação de elegibilidade geral para primeira participação e de condições para reaplicação.
- Consulta de condições em diálogo e filtros interativos.
- O acesso do participante é validado **no sistema específico de cada pesquisa**. O catálogo não consulta nem afirma permissões individuais.
- A página **não coleta senhas, PINs ou dados sensíveis**. O login único e o acesso ao histórico consolidado ainda não estão publicados, e a interface explica essa limitação.
- Os relatórios privados não são tornados públicos no GitHub Pages.
- A administração permanece separada em https://impulso-pesquisas-admin.prrogeriobraga.chatgpt.site.
